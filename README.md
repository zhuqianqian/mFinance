# 掌上资产 · mFinance PWA

一个本地离线、可装到 iPhone 主屏幕的个人资产负债管理应用。纯前端、免构建，数据只存在你自己的浏览器里。

## 功能
- **首页**：净资产（含环比 / 同比）、总资产、总负债、流动资金、负债率；带纵坐标的趋势折线、按账户类别切换资产 / 负债构成的环形图。
- **账户**：五类账户
  - 资产账户（银行储蓄 / 公积金 / 支付宝 / 微信 / 云闪付 / 其他现金）
  - 信用卡（按总额度与可用额度自动算欠款）
  - 固定资产（房产按每平方米单价×面积手动估值；车辆按月折损率复利折旧，可一键计算当前估值；旧年折损率自动换算为等效月率）
  - 股票 / 基金（持仓×最新价；支持联网获取最新价）
  - 贷款（等额本息 / 等额本金 / 先息后本；四种日计息惯例；利率变更、提前还款、还款计划）
- **对账**：设定每月对账日，校准各账户余额后记录当日快照，首页图表由快照序列驱动。信用卡输入可用额度自动计算欠款；贷款、投资、固定资产按对账日自动估值，可手动覆盖。
- **我的**：对账日、深浅色主题、数据导出 / 导入（JSON）、示例数据、清空。

## 本地预览
```bash
cd mFinance-pwa
python3 -m http.server 8777
# 浏览器打开 http://localhost:8777/index.html
```
（必须用 http 服务器打开，直接双击 index.html 会因 ES Module / Service Worker 限制而无法运行。）

计算逻辑回归测试（Node.js 22+）：`node --test tests/models.test.mjs`。

## 部署到 iPhone（静态托管）
1. 把整个目录推到任意静态托管（GitHub Pages、Vercel、Netlify 等，必须 HTTPS）。
2. iPhone Safari 打开站点地址。
3. 分享菜单 → 「添加到主屏幕」。即可像 App 一样全屏使用，并支持离线。

## 数据与备份
- 数据保存在浏览器 `localStorage`，仅限本机、本浏览器。
- 换设备或清理浏览器前，请到「我的 → 导出数据」保存 JSON，再在新环境「导入数据」。
- 导入支持「合并」；整体覆盖请先「清空全部数据」再导入。

## 更新版本（重要）
Service Worker 采用缓存优先策略以支持离线。开发和样式调整期间不改版本号；**仅在明确要求升级发布时**，把 `sw.js` 顶部的
`const CACHE = 'mfinance-v4'` 版本号 +1，并同步更新 `js/views/settings.js` 中的 `APP_VERSION`。
「我的」页面会显示应用版本；用户下次联网打开会下载新缓存，重新打开或刷新页面后使用新版。

## 关于联网行情
股票 / 基金的「联网更新」走公开接口（基金=天天基金，A股=腾讯行情）的 JSONP 注入，
规避跨域。部分网络环境或接口变动可能导致失败，此时回退为手动录入最新价即可，不影响其他功能。

## 关于贷款日计息
- 等额本息 / 等额本金：常规每期按月利率（年利率 ÷ 12）计息，符合国内房贷习惯；
  放款日到首次还款日的「首期零头」按所选日计息惯例（30E/360、30/360、实际/360、实际/365）计算。
- 先息后本：每期利息按所选日计息惯例计提，本金在末期一次归还。
- 利率变更自生效日起对剩余本金与剩余期数重算；提前还款支持「缩短期限」与「减少月供」。

## 目录结构
```
index.html            应用外壳 + PWA/iOS meta
manifest.webmanifest  安装清单
sw.js                 Service Worker（离线缓存，更新时改版本号）
css/app.css           设计系统（深浅色、安全区适配）
js/                   app 路由 + store/models/loan/valuation/charts/icons + views/*
js/forms.js           浮动标签输入、下拉框、选择器的共享构件
assets/ icons/        应用图标与机构徽标
```
